# MCP Baseline

## Purpose
Track the intended MCP baseline for the local Cline control plane.

## Current policy
- Enable only the servers that are actually needed
- Do not treat disabled servers as capability
- Prefer verified working servers over inflated server counts

## Baseline tracking fields
- Server name
- Enabled/disabled
- Purpose
- Verification status
- Notes

## Notes
Use the Google Sheet "Cline Control Plane Registry" for the cloud-side registry view.
